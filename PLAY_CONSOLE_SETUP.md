# Google Play Console - Quick Setup

## Create New App
1. Dashboard → Create app
2. Fill in:
   - App name: **Pocket Digger**
   - Default language: **English (United States)**
   - App or game: **Game**
   - Free or paid: **Free**
   - ✓ Declarations (check all boxes)
   - Create app

## Complete Required Tasks (Dashboard will show these)

### 1. App Access
- All functionality available without special access → Next

### 2. Content Rating
- Email: your email
- Category: Casual Game
- Violence: No
- Sexual content: No
- Drugs: No
- Next → Save → Submit

### 3. Target Audience
- Age groups: 13-15, 16-17, 18+
- Appeal to children: No
- Next → Save

### 4. Data Safety
- Does your app collect data? **No**
- Next → Save

### 5. App Category
- Category: Game → Casual
- Save

### 6. Store Listing (MINIMUM for Internal Test)
- App icon: Use any 512x512 PNG (even a screenshot)
- Feature graphic: 1024x500 PNG (can be solid color)
- Screenshots: Take 2 screenshots from Unity Editor
- Short description: "Dig through sand to guide marbles home"
- Full description: "A relaxing physics puzzle game"
- Save

## Upload Your Build
1. Testing → Internal testing
2. Create new release
3. Upload your .aab file
4. Release name: 0.1.0
5. Release notes: "First test build"
6. Save → Review release → Start rollout

## Add Testers
1. Internal testing → Testers
2. Create email list → Name: "Friends"
3. Add emails (including yours)
4. Save
5. Copy the opt-in link
6. Send to testers!

Your app will be ready in 10-30 minutes!
